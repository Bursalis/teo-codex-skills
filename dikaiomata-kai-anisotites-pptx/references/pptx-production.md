### 6. Deliverable 4 — full PowerPoint deck (explicit second phase only)

- Create the deck with the `presentations` skill from `[Templates]\Rights&Inequality.potx`. Inspect the template and its layouts before editing.
- Before writing or running a presentation builder, bootstrap a **new isolated build directory** for the current run. On Windows, create a `node_modules` junction in that directory pointing to the Node package directory returned by the workspace dependency loader. Set both `NODE_PATH` and `RUNTIME_NODE_MODULES` to that same package directory for the builder and the finalizer. If any project path contains literal square brackets, use PowerShell's `-LiteralPath` form when changing directories or inspecting paths; otherwise PowerShell can treat the path as a wildcard pattern and run the preflight in the wrong folder.
- Run a small import preflight from the new build directory to confirm that `@oai/artifact-tool` resolves before authoring slides. If the import fails, stop before building the deck, diagnose the runtime path or junction, repair it, and rerun the preflight. Do not fall back to a previous builder directory or deck merely because it already has a working dependency link.
- Export the deck to `[Παραδοτέα]` as `ΔΑ - [αριθμός ενότητας] - [τίτλος ενότητας].pptx`. Use the cover arrangement specified below; the full, exact unit title remains the presentation title.

#### Slide-plan gate

Only after the user explicitly requests the PPTX following review of the first three deliverables, produce a fresh analytical slide plan. Before planning, confirm the exact reviewed versions of the critical summaries, final script and outline to use. Derive every claim and all visible slide wording from the final script; use the summaries and outline to preserve analytical coherence and section structure, not as independent sources of new slide content. For each slide record its title, source script section, pedagogical function, proposed slide wording, selected template layout, a specific visual recommendation or an explicit decision that no visual is useful, and the complete APA footer reference. For a permitted unpaginated Greek-example web source, record its complete APA reference and stable URL. Do not create or populate speaker notes. For every substantive slide, record a `visual decision`: either (a) why the selected visual would materially clarify the argument or make the slide more legible and engaging, together with the specific visual relation required; or (b) why no visual would add analytical or pedagogical value to that particular slide. A slide may introduce a concept, explain a mechanism, develop an example, compare approaches or hold a central claim. Do not build a deck from a generic list of short conclusions.

At least one third of all substantive slides must use `Content with Picture 3`, `Content with Picture 4` or `Content with Picture 12`; calculate the minimum by rounding the substantive-slide count up to the next whole number after dividing it by three. For this calculation, substantive slides exclude the cover, section headers and the final bibliography slide. Select a picture layout only where the specific visual relation is analytically meaningful and the actual text density fits it. Every remaining substantive slide must retain the explicit no-visual rationale above; do not default them collectively to `Content`.

For every slide, the plan must also contain a provisional **build contract**. This is an implementation-ready record, not a claim that text fit has already been proved at pixel level. After inspecting the actual template, it must identify the layout and the verified title, body, bibliographic-footer and, where applicable, picture placeholders by name, type, `idx` and bounds; require the picture area to remain empty and record the specific visual recommendation; and specify the expected number of bullets and the template-native text size for every populated placeholder. If a rendered trial shows that a placeholder does not fit at its native size, also record the overflow condition, original size, effective size and smallest local reduction that resolves it. For cover, section-header and bibliography slides, record the corresponding verified template text boxes and their special rules instead. Identify placeholders by layout name, type, `idx` and geometry together, never by text-box order or a generic `footer` lookup.

Select the provisional contract from the final script's actual content density, the length of the title and APA reference, the available text area of the inspected layout, and whether a visual relation is analytically meaningful. The contract must reserve safe space for the title, body, footer and, where applicable, a wholly separate picture area. It must never rely on a generic or inherited `footer` lookup.

The build contract may be revised during feasibility checking or construction, but only through a recorded, controlled change: choose a different approved layout, remove a non-essential visual relation, shorten a title without changing its argument, split the material across further slides, or—only after a rendered native-size trial—apply the smallest necessary font-size reduction in the one affected placeholder. Update the slide plan and contract before export, and preserve the same script-derived claim, visible citations and footer. Never use this flexibility to add a new claim, example or source, move text into a picture area, substitute an arbitrary text box, apply a font-size change across a slide, layout or deck, or reduce text below 22 pt.

For every section of the reviewed final script, plan one to four substantive slides from its actual conceptual density: use one for a short introduction, recap or minor transition; normally two for a standard section; and three or four only where the section develops several distinct mechanisms, theoretical distinctions, examples or stages of an argument. First divide the section into slide-sized conceptual parts. Then write three to five complete, grammatically sound, script-faithful sentences for each part, to become the slide's bullet points. The deck's total number of slides follows this section-level division alone; do not impose a numerical range or add, remove or compress material merely to reach a target total. Record the final exact total in the slide plan before export.

Use the general `Content` layout for substantive slides whose message is best carried by text alone. Use an approved `Content with Picture` layout where a future image, map or figure would materially advance explanation, comparison or interpretation, or make the presentation more legible and engaging. Use picture layouts regularly across a deck where they genuinely suit the argument, but there is no mandatory numerical ratio between picture and `Content` layouts.

Apply `teo-writing-academic` to all written slide material, adapting it to presentation legibility. Treat slide writing as a high-fidelity transformation of the reviewed final script, not as a fresh paraphrase. Prefer complete sentences already used in the script, carrying them over verbatim when they fit; when a small edit is needed for slide length or grammar, preserve the sentence's syntax, actors, claim, qualification and analytical emphasis. Do not substantially rephrase, flatten, fragment or replace the prose with keywords, nominalisations or slogan-like summaries. Where a script sentence is too long, split it at a natural syntactic boundary into one or two complete sentences without changing its meaning. Slide wording should retain the analytical precision, clarity and developed argument found in the critical summaries and lecture script, while remaining faithful to the final script as its sole content source. Keep actors, mechanisms and consequences visible and place complete APA references in the slide footer.

Every substantive analytical slide must have:

- a **bold** title in **36 pt** that names the argument, question or analytical function, rather than merely naming a topic or author;
- **three to five** bullet points, with up to **six** permitted only when the content genuinely requires it and readability remains intact; and
- bullet points that are each one complete, self-contained sentence or, where necessary to preserve a distinction or mechanism, two short complete sentences.

Do not use fragmentary phrases, coded keywords, uniformly terse points, formulaic three-part lists or a mechanically identical bullet count, length or rhythm. Bullet points may vary in length, but every body placeholder begins with the template's native typography. First test the approved content at that inherited size. Only when a rendered trial shows clipping, overflow or collision may the builder reduce the font size in that one affected body placeholder, using the smallest reduction necessary and recording the original size, effective size and reason in the build contract. Never reduce text below 22 pt, apply a global font-size override or use automatic shrink-to-fit. Never override line spacing, paragraph spacing, bullet indentation, font family, colour or alignment. If the content still cannot fit legibly, select a more suitable layout or distribute it across more slides.

Every substantive analytical slide must reserve a stable footer zone exclusively below the body text and within the same text column. Its left edge and internal alignment must be left-aligned with the main body text box. It must not overlap the title, body text, image area, template logo or any master element. The footer contains only the complete APA reference for the source that supports the slide's specific message, in the template's inherited footer typography, including all required APA details, punctuation and italicisation. For a permitted unpaginated Greek-example web source, this complete APA reference includes its stable URL.

Do not use page numbers, shortened author-year references, right alignment, labels or explanatory phrases such as `Πηγή:`, `Σύνοψη της ενότητας`, `Από το κείμενο της διάλεξης` or `Πλήρεις εγγραφές στο κείμενο της διάλεξης` in this footer. Never place it in or across a picture placeholder. If a complete APA reference does not fit at the native size without overlap, first redesign the slide plan, select a suitable layout or distribute its content; only when a rendered native-size trial confirms the problem may the builder apply the smallest documented local reduction, without changing spacing, truncating entries, omitting required material or violating the picture area.

The single final bibliography slide is the only exception to the substantive-slide bullet rule. It must list all and only works cited in the final script and deck, in complete APA format, with required italicisation and strict alphabetical order. Do not use bold in the body of its bibliographic entries. Use the template's native bibliography typography first; do not enlarge its type or spacing when it has few entries. Reduce type only on this bibliography slide when a rendered native-size trial establishes that complete entries cannot otherwise fit on its one required slide; record the original size, effective size and reason. Before building, test this capacity in the actual template; if complete entries cannot fit safely, return to the slide plan and resolve the source/slide allocation before proceeding rather than creating a second bibliography slide or truncating entries.
